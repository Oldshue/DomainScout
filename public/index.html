⚙ Optional: CZDS Zone Files (.com/.net/.org drops)
For .com/.net/.org dropped domains, register a free ICANN account:
1. Go to czds.icann.org → Create Account
2. Request access to .com, .net, .org zone files (approved in ~24h)
3. Create .env in the project root:
CZDS_USER=your@email.com
CZDS_PASS=your_password
4. Restart → node server/index.js
